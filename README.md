Merpati Nusantara: an original 3D island-hopper flight game. Fly a small prop plane over a procedurally built Indonesian archipelago — sea, sandy islands, palm trees and one island airstrip. Thread all 8 glowing rings around the islands, mind the fuel, then land on the runway to complete the sortie. Keyboard and mouse, no network, runs entirely from static files.

## Play it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. Or open `game/index.html` from any static server.

Controls: W/S or Up/Down pitch, A/D or Left/Right bank and turn, Shift throttle up, Ctrl throttle down, mouse drag to look around, P pause, R restart, M mute.

## Hand it in

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
